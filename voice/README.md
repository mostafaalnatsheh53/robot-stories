# Voice recordings (not used)

Team decision (15 Nov 2026): all story videos use the English computer narration (Piper, `en_US-ljspeech`, public domain)
in both languages. The Arabic videos have Arabic subtitles and Arabic on-screen text. There is no Arabic narration.

The build script still supports recorded voices (`voice/<id>.<lang>.<nn>.wav`, one file per sentence) in case
the project continues after the hackathon, but nothing needs to be recorded now.
